# 项目上下文

## 一、项目信息

- 项目名称：Multiagent Collaboration Skill
- 讨论主题：两分钟辅助监测的默认启用策略
- 创建日期：2026-08-09
- 创建者：Rainier

## 二、任务与目标

- 任务描述：确定辅助监测（每两分钟扫描工作区）的默认启用策略——默认启用 / 默认关闭 / 显式询问后启用。
- 期望结果：收敛出一个可执行方案，供写入协作规范。

## 三、权威输入

- 结构化需求：多 Agent 协作 Skill 的权威需求（已确认 v0.7）
- 本讨论由 Skill 驱动，参与者通过共享目录协作；独立提案阶段各参与者互不可见
