# <agent-id> 独立提案文档

> 使用说明：独立提案阶段，每个 Agent 只接触指令提供的项目上下文与自身密封输入视图；**成稿前不得读取其他提案文件或主讨论文档**。写入 `.multiagent/views/<agent-id>/outputs/提案文档.md`，`<agent-id>` 与 `.multiagent/state.json` 的 `expected_participants` 身份键完全一致。UTF-8 编码。

## 独立性声明

- agent_id: <与 expected_participants 一致>
- 提案形成时间: <YYYY-MM-DD HH:mm> (Asia/Shanghai)
- 成稿前读取输入清单: [项目上下文, 自身身份, 自身提案文件]
- 是否在成稿前查看他案: 是 / 否
- 若查看，涉及来源: <其他提案文件路径 / 主讨论文档 / 其他>
- 降级方式: 无 / 会话内成稿后追加主讨论文档（如实描述）
- 污染状态自评: 未污染 / 疑似污染 / 已污染
